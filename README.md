# Trikks Tweaks

A modular quality-of-life and interface addon for the **WoW Forever** client. Every feature is its own module: **nothing is on by default**, so you switch on exactly what you want and leave the rest alone.

Open the settings with **/trikks** (or the minimap button / addon compartment).

## Install
Copy `TrikksTweaks` (and optionally `TrikksReskin`) into `World of Warcraft\_forever_\Interface\AddOns\`.

## Modules

**Interface** – Class Portraits, Centered Auras (Edit Mode, per layout), Party Position, Dark Mode, Mouseover Bars, Minimap (square map, wheel zoom, stats inside the map, movable buttons, button bin, zone bar removal), Clutter Text, Tooltips, Hide Blizzard Frames, Character Extras

**Quality of Life** – Automation, Dialog Keys (space / 1-9 for gossip and quests), Chat (history, `/copychat`, class colours, filters), Social, Consumable Macros, Vendor & Bags, Movable Windows, IDs & Links, Small Helpers

**System** – Camera & Visuals, Sound Muting

**Tools** – Setups

**Fun** – Four in a Row (`/c4`)

## Trikks Reskin
Companion addon (requires Trikks Tweaks): a flat, minimalist reskin of Blizzard's windows, progress bars, gear slots and tooltips, plus clean square action buttons.

## Repository layout
- `TrikksTweaks/` – core addon
- `TrikksReskin/` – reskin addon
- `media-curseforge/` – logo for the CurseForge page
